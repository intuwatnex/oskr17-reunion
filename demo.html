จำลอง flow ลงทะเบียน → รับอีเมลยืนยัน → ตั้ง/เปลี่ยนรหัสผ่าน → แก้ไขข้อมูล → ล็อกอิน Connection Map ด้วยอีเมล+รหัสผ่าน → ใช้งาน (ข้อมูลทั้งหมดเป็นข้อมูลสมมติ)

  1. 1. กรอกฟอร์มลงทะเบียน + Connection Map
  2. 2. ยืนยันการลงทะเบียนสำเร็จ
  3. 3. เช็คอีเมล (QR + ลิงก์จัดการข้อมูล)
  4. 4. ตั้ง/เปลี่ยนรหัสผ่าน
  5. 5. แก้ไขข้อมูลส่วนตัว
  6. 6. ล็อกอิน Connection Map (อีเมล+รหัสผ่าน)
  7. 7. ใช้งาน Connection Map
